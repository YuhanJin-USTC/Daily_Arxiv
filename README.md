# Daily-Arxiv generated data

Shared raw arXiv metadata, separate English/Chinese AI interpretations, and persistent discovery/delivery state. Source code and operating instructions live on [main](https://github.com/YuhanJin-USTC/daily-arxiv/tree/main).

Initial migration sources are retained in the legacy Chinese and English repositories. `migration-manifest.json` records exact source commits, file hashes, availability and byte-preservation mappings. Historical gaps are baseline-only and do not enter automatic generation or mail. No historical notification was queued.

AI interpretations require scientific review; papers remain attributed to their authors and arXiv.
