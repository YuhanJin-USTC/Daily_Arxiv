Result: 在湍流旋流稳定燃烧器的大涡模拟数据上验证：贝叶斯模型比较选择了三高斯脉冲响应，与先前工作的物理解释一致；相比系统识别方法，产生更少虚假特征的脉冲响应；能够直接强制执行已知的低频增益；对显著缩短的记录长度具有鲁棒性。

Conclusion: 贝叶斯框架为火焰脉冲响应识别提供了系统化方法，自动处理模型选择和参数调整，能够整合物理先验知识，对计算成本高的模拟数据特别有吸引力，因为可以减少所需数据长度。

Abstract: The impulse response of a flame to acoustic velocity perturbations is a key quantity for predicting thermoacoustic stability, but its identification from sparse, noisy observations requires solving an ill-posed inverse convolution problem. This is typically achieved with system identification methods, which require hand-tuning of regularization, model order, and sampling parameters, and provide no principled mechanism for incorporating prior physical knowledge. In this paper, we reformulate the identification problem within a Bayesian framework. The impulse response is represented as a physically motivated distributed time delay model, whose parameters correspond to convective delays and dispersive broadening. For a given number of pulses, the model parameters are inferred from the data using Bayesian parameter inference. The number of pulses is then selected using Bayesian model comparison, which balances data fit against model complexity to identify the simplest model capable of explaining the data. The framework is demonstrated on broadband-forced large eddy simulation data from a turbulent swirl-stabilized burner. Bayesian model comparison selects a three-Gaussian impulse response for this flame, consistent with physical interpretations in previous work. Compared with system identification, the Bayesian approach produces impulse responses with fewer spurious features and enables straightforward enforcement of a known low-frequency gain. Finally, we show that the Bayesian approach is robust to significant reductions in recording length, making it appealing for impulse response identification from costly simulations, where there is an incentive to minimize computational cost.
